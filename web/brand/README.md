# Thunderden brand asset

`thunderden-horizontal-paper.svg` is copied unchanged from
[thunderden-brand](https://github.com/bitcoinerlab/thunderden-brand), revision
`00e282f7267dabec418bba652b7ac9905cb1add7`, under `logos/`.
It supplies the horizontal hardware markings in the laptop illustration and is
served locally, without a runtime dependency on GitHub.

The USB marking in `laptop.svg` uses the exact icon path from that same official
asset, without the wordmark. Only its placement and surface perspective change.
