# Inter

`InterVariable.woff2` is the unmodified upright variable font from
[Inter v4.1](https://github.com/rsms/inter/tree/v4.1/docs/font-files).
Its SHA-256 is `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`.

The original SIL Open Font License is included in `OFL.txt`. The website serves
the font locally and does not contact a font service.

## Terminus TTF

`TerminusTTF-4.49.3.ttf` is the unmodified regular font from
[Terminus TTF 4.49.3](https://files.ax86.net/terminus-ttf/files/4.49.3/terminus-ttf-4.49.3.zip).
Its SHA-256 is `f668ad7884635e112bcfa2ced6ccb9550128f643bf539cb049bd90bd8afbf4b3`.

The original SIL Open Font License and copyright notices are included in
`Terminus-OFL.txt`. The font is served locally for loading and the demo's
keyboard, camera and diagnostics dialogs. The surrounding website keeps Inter.
Use the recommended integer pixel sizes rather than fluid font sizing.
